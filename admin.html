Repozytorium GitHub Pages musi zawierać plik index.html z tej paczki. Token jest używany tylko w tej karcie i nie trafia do pamięci przeglądarki.

Wydawaj token tylko dla jednego repozytorium. Nie zapisuj go w HTML, na GitHubie ani na telewizorze. Publikowane dane i panel będą publicznie widoczne, ale bez tokenu nikt nie może zapisać zmian.

Najpierw wgraj stronę na GitHub Pages, potem połącz edytor z repozytorium.
